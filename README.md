# Talabat Product Codes

واجهة بسيطة للبحث عن المنتج برقم SKU وإنشاء باركود Code 128 وQR قابلين للمسح، مع اختيار نوع الكود والتبديل بين العربية والإنجليزية.

## التشغيل

```sh
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية. لاستخدام قارئ الأكواد على جهاز آخر، افتح رابط التطبيق من الجهاز نفسه.

## البيانات

عند أول زيارة، يطلب التطبيق رفع ملف بيانات المخزون بصيغة CSV قبل بدء الاستخدام. تُحفظ البيانات في متصفح المستخدم على جهازه فقط، ولا تُرسل إلى خادم؛ على كل مستخدم رفع ملفه من جهازه أو متصفحه. البحث يستخدم `sku_id`، والاسم من `product_name`، والباركود من `barcodes`. يمكن استعراض جميع أعمدة سجل الصنف من **عرض بيانات الملف كاملة**. لاستبدال الملف، افتح القائمة واختر **رفع بيانات المخزون**؛ يجب أن يحتوي على `sku_id` و`product_name` و`barcodes` أو أسماء الأعمدة القديمة `SKU` و`Item Name` و`Barcode`.

## النشر

أنشئ نسخة الإنتاج باستخدام `npm run build`، ثم انشر محتويات مجلد `dist` على أي استضافة للمواقع الثابتة. لا ترفع ملف المخزون إلى المستودع أو الاستضافة؛ كل زائر يرفع ملفه ويُحفظ في متصفحه. يظل الملف متاحًا على الجهاز والمتصفح نفسيهما فقط، ولا تنتقل البيانات بين الأجهزة أو المتصفحات.

تحتوي القائمة على معلومات المشروع وخيار التواصل عبر البريد. تسجيل طلبات صلاحية أو حفظ ملفات المستخدمين مركزيًا يحتاج إلى خادم وقاعدة بيانات، وهي غير مضمنة في هذا المشروع.

يعرض الباركود بصيغة Code 128 حتى للقيم ذات الأطوال المختلفة أو الأصفار في البداية، ويحتوي QR على نفس قيمة حقل `barcodes`. إذا لم يتوفر باركود، يستخدم SKU لإنشاء الكود ويوضح ذلك على الشاشة. يتطلب تحميل المكتبات أول مرة اتصالًا بالإنترنت عبر `npm install`؛ بعد ذلك تعمل الأكواد محليًا.
